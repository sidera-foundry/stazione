TOKENS FOR YOUR AGENTS

Every computer running one of your AI agent instances uses a token. A token is shown only once: save it as the environment variable STAZIONE_TOKEN on that computer and never paste it into a chat, an agent instructions file or a repository.

CONNECT THE COMPUTER WITH ONE COMMAND

On the agent's computer, open a terminal in the folder that holds your projects and paste this command. It asks the agent's name, saves the token encrypted without showing it and writes the protocol file. The command works once, within 15 minutes.

Node.js is needed on that computer (nodejs.org, LTS version).

Or connect by hand with the token

Copy this token now: once you leave the page you will not be able to see it again.

On Windows, in PowerShell on the agent's computer:

[Environment]::SetEnvironmentVariable("STAZIONE_TOKEN", "PASTE_THE_TOKEN_HERE", "User")

Then restart your agent so that it reads the variable.
