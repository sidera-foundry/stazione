Checking the station...

    1 · YOUR SECRETS

    This browser made them for you, right now: they are never sent anywhere. Each time you open this page you get a new set, so copy this one and use only this one.

    Save the whole block in your password manager. Without DATA_ENCRYPTION_KEY the encrypted data of the station cannot be read, and you need INVITE_CODE once, to create the owner account.

    2 · PUT THEM ON VERCEL

    1. Open your project on Vercel, then Settings, Environment Variables.
    2. Click in the first Key field and paste: Vercel splits the block into the four variables by itself. Save.
    3. No database yet? Storage, Create, Neon Postgres, in the region closest to you.
    4. Settings, Functions, Function Region: the same region as the database.
    5. Deployments, the last one, Redeploy. Then open this page again.

    With Docker the block goes in the .env file next to docker-compose.yml (or use node scripts/gen-secrets.js --docker).
